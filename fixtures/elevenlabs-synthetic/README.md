# Synthetic ElevenLabs fixtures

Everything in this folder is invented. No real delivery from ElevenLabs has been captured yet. The shapes follow ElevenLabs' public documentation, read on 16 November 2026, so a real payload may differ in details.

The ids, names and conversation text are made up. The phone numbers are in the range that North American numbering reserves for fiction. The audio event used in the tests is built in the test itself, because it is large.

When a real payload from a test agent exists, it replaces these files and the source can be called proven. Until then, treat the tests here as proof that the bridge handles the documented shapes, not as proof that it handles ElevenLabs.
